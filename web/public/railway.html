prueba6 — Despliegue en Railway

Esta página incluye los pasos mínimos para desplegar el backend Node.js en Railway y configurar la base de datos Postgres.

Paso 1 — Conectar tu repositorio

En Railway, crea un nuevo proyecto y elige Deploy from GitHub. Conecta el repositorio estebanvrsalovic/prueba6 y selecciona la rama fix/schedule-parsing.

Abrir Railway

Paso 2 — Variables de entorno

Añade las siguientes variables en Railway → Settings → Environment Variables:

DATABASE_URL=postgres://usuario:pass@host:5432/dbname
MQTT_BROKER=mqtt://broker:1883
SUPABASE_FUNCTIONS_BASE=https://xxxx.functions.supabase.co
SERVICE_ROLE_KEY=eyJhbGciOiJI...

Si pones DATABASE_URL, el servidor usará Postgres. Si no, usará SQLite local en el contenedor.

Paso 3 — Comando de arranque

Usa este comando para iniciar el servidor (desde la raíz del repo):

node web/server.js
Endpoints útiles
  • /api/schedule — GET/POST para gestionar horarios
  • /history?n=5 — obtener últimas lecturas
  • /esp32s3/schedule — MQTT topic para publicar horarios
Notas
  • Railway crea un contenedor para el servicio; asegúrate de asignar un plan si necesitas recursos persistentes.
  • Si quieres, puedo crear la plantilla de despliegue y añadir un botón en el README.
